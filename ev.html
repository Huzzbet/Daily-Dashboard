Feed format

The scanner accepts either an array of markets or {"markets":[...]}. Each market should contain type, label, probability/p/modelP, odds. Optional fields: source, game, note, line, player, team. This makes it easy to connect your bookmaker/odds collector later without changing the dashboard.

How to connect the automation

Your odds collector only needs to produce data/odds_today.json (or an API endpoint). BetIQ will fetch it, normalise the markets, combine prices with the supplied model probabilities, calculate implied probability, edge, EV and Kelly, then rank the opportunities. With GitHub Actions or your existing worker, that file can be regenerated automatically during the day.
